# Kernel 6.12 LTS Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Llamaste kernel from 6.6.70 to 6.12.78 LTS for PREEMPT_RT, AMD GPU improvements, QR panic codes, and broader hardware support.

**Architecture:** Buildroot custom kernel config (`br2-external/board/llamaste/linux.config`) + defconfig version bump. The 727-line linux.config is a fragment merged with kernel defaults. Jumping 6 minor versions (6.7→6.12) means Kconfig options may be renamed, split, or removed. Use `make linux-oldconfig` to catch changes, then manually review and enable new features.

**Tech Stack:** Linux 6.12.78 LTS, Buildroot 2024.02.9, x86_64

**Key Benefits:**
- **PREEMPT_RT** — deterministic inference latency (mainlined in 6.12)
- **AMD GPU improvements** — potential fix for EVO-X2 desktop mode
- **QR panic codes** — scannable debug info on kernel panic screens
- **EEVDF scheduler** — complete replacement for CFS, better latency
- **Intel Xe DRM** — available since 6.8, can enable for newer Intel GPUs
- **WiFi driver improvements** — rtw88/89, iwlwifi, ath11k/12k updates

**Risk Areas:**
- WiFi driver Kconfig renames (rtw88/89 may restructure between 6.6→6.12)
- DRM subsystem changes (buddy allocator, TTM, sched may reorganize)
- PREEMPT_RT interactions with watchdog, softdog, inference threads
- Buildroot 2024.02.9 kernel hash validation (may need hash update)
- New default configs that silently enable unwanted features
- linux-firmware version in Buildroot may be too old for 6.12 drivers
- PXE boot bzImage-pxe uses separate config — not upgraded in this plan (uses same kernel source, just different initramfs embedding; rebuild separately if PXE needed)

**Out of Scope:**
- PXE boot `bzImage-pxe` — uses a separate kernel config with `CONFIG_INITRAMFS_SOURCE`. Rebuild separately after main kernel verified. The PXE initramfs is kernel-version-agnostic (busybox), but `/lib/modules/` paths change.

### Task 3: Enable PREEMPT_RT

**Files:**
- Modify: `br2-external/board/llamaste/linux.config`

- [ ] **Step 1: Check current preemption model**

The 6.6.70 config likely uses `PREEMPT_VOLUNTARY` (default). Verify:
```bash
grep -i preempt /mnt/d/Llamaste/br2-external/board/llamaste/linux.config
```

- [ ] **Step 2: Replace preemption model in linux.config**

The preemption model is a Kconfig `choice` block — only one can be active. We must explicitly remove the old and set the new. In `linux.config`:

**Remove** (or comment out):
```
CONFIG_PREEMPT_VOLUNTARY=y
```

**Replace with:**
```
# ---------------------------------------------------------------------------
# Real-time preemption (PREEMPT_RT) — deterministic inference latency
# Mainlined in 6.12. Trades throughput for lower worst-case latency.
# Critical for LLM inference: ensures token generation isn't delayed
# by kernel work (especially on single-CPU/low-core systems).
# ---------------------------------------------------------------------------
# CONFIG_PREEMPT_VOLUNTARY is not set
# CONFIG_PREEMPT is not set
CONFIG_PREEMPT_RT=y
```

**Important:** Both the explicit `# ... is not set` lines AND the `=y` line are needed. Kconfig fragment merge with `choice` groups can behave unexpectedly if old selections aren't explicitly disabled.

- [ ] **Step 3: Verify PREEMPT_RT dependencies**

```bash
cd /root/llamaste-build/output/build/linux-6.12.78
grep -A5 "config PREEMPT_RT" kernel/Kconfig.preempt
# Check for: depends on EXPERT && ARCH_SUPPORTS_RT

# Verify ARCH_SUPPORTS_RT is set on x86_64 (should be auto-selected)
grep "ARCH_SUPPORTS_RT" arch/x86/Kconfig
# Expect: select ARCH_SUPPORTS_RT
```

We already have `CONFIG_EXPERT=y`. `ARCH_SUPPORTS_RT` is auto-selected by x86 arch Kconfig. If either is missing, PREEMPT_RT silently won't appear as an option.

- [ ] **Step 4: Check watchdog compatibility**

Our supervisor uses softdog with 300s timeout + kicker thread. PREEMPT_RT changes timer behavior. Verify softdog still works:
```bash
grep -r "SOFT_WATCHDOG\|SOFTDOG" drivers/watchdog/Kconfig
```

No code changes expected — softdog uses hrtimers which work with RT. But verify in testing.

- [ ] **Step 5: Commit PREEMPT_RT enablement**

```bash
cd /mnt/d/Llamaste
git add br2-external/board/llamaste/linux.config
git commit -m "feat: enable PREEMPT_RT for deterministic inference latency"
```

## Rollback Plan

If the 6.12 kernel causes regressions that can't be quickly fixed:

1. Restore backup config: `cp linux.config.6.6.70.bak linux.config`
2. Revert defconfig: change version back to `"6.6.70"`
3. Full rebuild: `make linux-dirclean && make`
4. The old ISO in `backups/v0.2.1/` is always available
